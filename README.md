# Taiwan 臺灣

**https://taiwan.pinkoa2.lol/**

Our month in Taiwan, October 2026: a map that follows the route as you scroll, with photos from each stop.

Map data © OpenStreetMap contributors. Working notes are in [docs/how-it-works.md](docs/how-it-works.md).

Update the live site (on the server, in the repo's folder):

```
git pull && REFRESH_PHOTOS=1 DELETE_ZIP=1 SITE_DIR=/srv/taiwan docker compose run --rm --build build
```
